# VentureLens | 开源项目雷达

Public Edition v1.0. A browser-based GitHub project research workspace.

Live demo: https://zht3677966.github.io/venturelens/

Features: GitHub repository search, filters, source details, local watchlist and notes, Markdown export, workflow and architecture view.

Architecture: HTML/CSS/JavaScript on GitHub Pages; GitHub public REST Search API; localStorage for research notes; short session cache. No API keys embedded.

Scope: public repository signals, not investment predictions. No background scheduler or LLM analysis. Data availability depends on GitHub rate limits. Notes stay in this browser.

The research workflow references Scout; this public frontend is a separate implementation.
