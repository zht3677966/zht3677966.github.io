02 / ARCHITECTURE

公开版如何运行

GitHub Pages 提供静态 HTML、CSS、JavaScript。浏览器通过 HTTPS 调用 GitHub Search REST API；关注名单和笔记保存在 localStorage。

无需登录或填写密钥。搜索有 15 秒超时、错误提示与 5 分钟会话缓存。限流后等待重试，不展示伪造结果。

03 / EVIDENCE

证据与边界

展示仓库链接、描述、语言、许可证、星标、Fork、创建时间和最后推送时间，并标注读取时间。

本版没有调用大模型，没有自动投资评分，也没有后台定时任务。它发现的是开源仓库线索，仍需人工核实团队、产品和商业进展。

04 / PROJECT CONTEXT

从本地工作台到公开体验版

研究流程参考 Scout。本地版本基于 Scout 改造；本公开版独立实现网页界面与 GitHub API 集成，适配个人网站的静态托管环境。

后续可增加服务端任务队列、更多数据源及 Dify 分析。以上均为后续计划，不计入本版已完成功能。
